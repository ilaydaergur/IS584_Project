\title{Tip-of-the-Tongue Retrieval with Transformer-Based Reranking:\\
BM25, Cross-Encoder, and Bi-Encoder Compared}

\author{\IEEEauthorblockN{\.Ilayda Erg\"ur}
\IEEEauthorblockA{Department of Multimedia Informatics\\
Middle East Technical University\\
Ankara, Turkey\\
ilayda.ergur@metu.edu.tr}}

\maketitle

\begin{abstract}
This paper presents a complete investigation of transformer-based reranking
for Tip-of-the-Tongue (ToT) retrieval on the TREC-ToT 2024 dataset.
Three retrieval systems are evaluated on the 2025/dev1 query set
(142 queries, 3.18M Wikipedia documents):
a BM25 baseline tuned via a Weights \& Biases parameter sweep,
a cross-encoder reranker (\texttt{ms-marco-MiniLM-L-6-v2}),
and a bi-encoder reranker (\texttt{all-MiniLM-L6-v2}).
BM25 achieves the highest performance (RR@10~=~0.0751),
while neither neural model significantly improves over it
(Wilcoxon signed-rank: $p=0.1023$ and $p=0.3382$ respectively).
Subgroup analysis reveals that neural models help on short queries
but are consistently hurt on the long narratives that characterise the ToT task.
Interpretability analysis via t-SNE embedding projection and sentence-level
cross-encoder attribution identifies query truncation and
semantic mismatch with MS-MARCO-trained models as the primary failure modes.
All code and results are publicly available.
\end{abstract}

\begin{IEEEkeywords}
tip-of-the-tongue retrieval, BM25, cross-encoder, bi-encoder, Wilcoxon test,
interpretability, t-SNE, TREC, sentence transformers
\end{IEEEkeywords}

\section{Introduction}
% ══════════════════════════════════════════════════════════════════════════════

Tip-of-the-Tongue (ToT) retrieval~\cite{trec-tot} targets a distinctive
information need: the user recalls attributes of an entity but not its name,
and provides a long narrative description to retrieve it.
Compared with standard ad-hoc retrieval, ToT queries average 121--238 words,
have near-zero lexical overlap with relevant Wikipedia documents, and
describe entities using subjective memory cues rather than precise keywords.
These properties make ToT an ideal stress test for transformer-based rerankers.

We investigate three research questions (RQs):
\begin{itemize}
  \item \textbf{RQ1:} Does cross-encoder reranking significantly improve
        retrieval over BM25 on ToT queries (Wilcoxon, $\alpha=0.05$)?
  \item \textbf{RQ2:} Does query length moderate the reranker's gain,
        given the 512-token input constraint?
  \item \textbf{RQ3:} Does a bi-encoder---which avoids the truncation
        problem by encoding queries and documents independently---perform
        better than the cross-encoder on this task?
\end{itemize}

Phases~1 and 2 established the dataset characteristics and BM25+cross-encoder
baseline.
This report closes the loop by adding the bi-encoder (RQ3),
conducting interpretability analysis, and performing systematic error analysis.

\section{Dataset and Evaluation Setup}
\label{sec:dataset}
% ══════════════════════════════════════════════════════════════════════════════

The TREC Tip-of-the-Tongue 2024 corpus~\cite{trec-tot} contains
3{,}185{,}450 English Wikipedia documents (mean length: 6{,}700 words).
We evaluate on the \texttt{trec-tot/2025/dev1} split (142 queries with
public relevance judgements), accessed via \texttt{ir\_datasets}~\cite{irdatasets}.

Three metrics are reported: \textbf{RR@10} (mean reciprocal rank at 10),
\textbf{nDCG@10}, and \textbf{R@100} (recall in the top 100).
RR@10 is the primary metric, as ToT is fundamentally a
single-relevant-document task: the user wants to identify one forgotten item.
All metrics are computed with \texttt{ir\_measures}~\cite{irm} via
\texttt{pt.Experiment}.

\section{Modeling}
\label{sec:modeling}
% ══════════════════════════════════════════════════════════════════════════════

\subsection{BM25 Baseline}

BM25~\cite{bm25} was indexed with PyTerrier's \texttt{IterDictIndexer}
over the full 3.18M-document corpus.
A 2{,}000-character text snippet is stored per document as metadata,
providing the rerankers with a passage for scoring without a second corpus pass.
Retrieval returns 100 candidates per query.

\subsection{Cross-Encoder Reranker}

The cross-encoder \texttt{ms-marco-MiniLM-L-6-v2}~\cite{wang2020}
concatenates each (query, document) pair and passes it through a 6-layer
MiniLM model fine-tuned on MS-MARCO relevance labels.
Because ToT queries average 121--238 words, fitting within the 512-token
joint input limit requires truncating each query to its first 100 words,
discarding up to 60\% of the narrative.

\subsection{Bi-Encoder Reranker}

The bi-encoder \texttt{all-MiniLM-L6-v2}~\cite{reimers2019} encodes
queries and documents \emph{independently} into a shared 384-dimensional
vector space; relevance is scored by cosine similarity.
This avoids the 512-token joint-input bottleneck: the full 512-token
budget is allocated separately to the query and to the document snippet,
so no query truncation is required.
Embeddings are L2-normalised; inference uses batch size 64 on MPS.

\section{Experimentation and Tuning}
\label{sec:exp}
% ══════════════════════════════════════════════════════════════════════════════

\subsection{BM25 Parameter Sweep (Phase 2)}

A grid sweep over $k_1 \in \{0.5, 1.0, 1.2, 1.5, 2.0\}$ and
$b \in \{0.3, 0.5, 0.75, 1.0\}$ (20 runs) was logged to Weights \& Biases.
The best configuration was $k_1=1.2$, $b=0.75$ (RR@10~=~0.0751),
which is the commonly recommended BM25 default~\cite{bm25}.

\subsection{Bi-Encoder Sweep (Phase 3)}

A $2 \times 2$ sweep was run over two model architectures and two
rerank depths; all four runs are logged to the same WANDB project.
Table~\ref{tab:bisweep} shows the results.
\texttt{all-MiniLM-L6-v2} at depth~100 achieves the best balance of
RR@10 and R@100 and is used for all subsequent evaluation.

\begin{table}[t]
\caption{Bi-Encoder Sweep Results (RR@10 primary metric)}
\label{tab:bisweep}
\centering
\begin{tabular}{lccc}
\toprule
Model & Depth & RR@10 & R@100 \\
\midrule
msmarco-distilbert-base-v4 & 100 & 0.0329 & 0.2183 \\
msmarco-distilbert-base-v4 &  50 & 0.0441 & 0.1761 \\
all-MiniLM-L6-v2           &  50 & 0.0470 & 0.1761 \\

\section{Evaluation}
\label{sec:eval}
% ══════════════════════════════════════════════════════════════════════════════

Statistical significance is assessed with the two-sided Wilcoxon signed-rank
test on paired per-query RR@10 scores~\cite{demsar2006}.
This non-parametric test is appropriate for IR metrics, which are
non-normal and heavily zero-inflated.
Ties in the difference distribution are handled by the zero-method
(pairs with identical scores are excluded from the ranking).

\subsection{Statistical Testing (RQ1 and RQ3)}

Table~\ref{tab:wilcoxon} shows the Wilcoxon signed-rank test results.
Neither neural model significantly outperforms BM25 at $\alpha=0.05$.
The cross-encoder is numerically worse (mean $\Delta=-0.029$, $p=0.1023$),
confirming the Phase~2 finding.
The bi-encoder is also worse than BM25 (mean $\Delta=-0.022$, $p=0.3382$)
but better than the cross-encoder ($\Delta=+0.007$), with neither
difference reaching significance.

\textbf{Answer to RQ1:} Cross-encoder reranking does not significantly
improve over BM25 ($p=0.1023$).

\textbf{Answer to RQ3:} Bi-encoder reranking does not significantly
improve over BM25 either ($p=0.3382$), though it outperforms the
cross-encoder numerically, supporting the hypothesis that query
truncation is the main bottleneck in the cross-encoder.

\subsection{Subgroup Analysis (RQ2)}

Table~\ref{tab:rq2} and Figure~\ref{fig:subgroup} show per-subgroup
RR@10 split at the median query length (121 words).
BM25 is strongest on long queries (RR@10~=~0.1020), where both neural
models lose substantially (CrossEnc: 0.0306, BiEnc: 0.0603).
On short queries, the cross-encoder narrowly surpasses BM25
(0.0602 vs.\ 0.0511), while the bi-encoder falls below it (0.0473).

\textbf{Answer to RQ2:} Query length strongly moderates neural reranker
effectiveness. The cross-encoder is hurt most on long queries due to
truncation; the bi-encoder is also hurt, but less severely, as it
can encode the full query independently.

\section{Interpretability and Error Analysis}
\label{sec:interp}
% ══════════════════════════════════════════════════════════════════════════════

\subsection{Bi-Encoder Embedding Space (t-SNE)}

Figure~\ref{fig:tsne} projects bi-encoder embeddings of all 142 queries
and their top-1 retrieved documents into 2D using t-SNE~\cite{maaten2008}.
Queries (squares) and their top-1 documents (circles / triangles)
are broadly separated in the embedding space, indicating that
\texttt{all-MiniLM-L6-v2}---trained on short MS-MARCO queries---does
not place these long narrative descriptions close to their relevant
Wikipedia documents.
Points where the top-1 retrieved document is relevant (green) are
spread throughout the space rather than clustering near their query,
confirming that the bi-encoder's success on individual queries is
not driven by systematic semantic proximity.

\begin{figure}[t]
  \centering
  \includegraphics[width=\columnwidth]{tsne_embedding_space.png}
  \caption{t-SNE projection of bi-encoder embeddings for all 142 queries
           (squares, blue) and their top-1 retrieved documents:
           relevant (circles, green) and irrelevant (triangles, red).
           The broad separation between queries and documents suggests
           that the model trained on short MS-MARCO queries does not
           generalise to 121--238 word ToT narratives.}
  \label{fig:tsne}
\end{figure}

\subsection{Cross-Encoder Sentence Attribution}

To understand \emph{which parts} of a ToT query drive cross-encoder
decisions, we apply a sentence-level ablation: each sentence is removed
in turn and the score drop is computed.
For queries where the cross-encoder wins, the first 1--2 sentences
(which survive the 100-word truncation) carry the highest attribution.
For queries where the cross-encoder loses, sentences in the middle and end
of the query---systematically discarded by truncation---show the highest
scores when retained, confirming that truncation removes the
most discriminative content.

\subsection{Error Analysis}

Systematic failure analysis across all three systems shows that
117 of 142 queries (82.4\%) result in \emph{all systems failing}
(no relevant document in the top 10).
Only 13 queries (9.2\%) are answered correctly by all systems,
and 11 queries (7.7\%) are answered only by neural models
(``Neural only'').
Crucially, just 1 query (0.7\%) is answered by BM25 but not by any
neural model (``BM25 only''), demonstrating that neural reranking
rarely introduces catastrophic failures on queries BM25 already handles.

The dominant failure mode is that the relevant document is not in
the BM25 top-100 candidate pool (R@100~=~0.218 means 78\% of queries
have no relevant document even in the top 100).
Both rerankers are fundamentally limited by this ceiling.

\section{Discussion}
\label{sec:discussion}
% ══════════════════════════════════════════════════════════════════════════════

Three findings emerge consistently across all experiments.

\textbf{BM25 is a strong baseline for ToT.}
Despite having no semantic component, BM25 outperforms both neural
rerankers. This is because the BM25 first stage---not the reranker---is
the bottleneck: if a relevant document is not in the top-100 candidates,
no reranker can recover it.

\textbf{Query length is the key modulator of neural reranker effectiveness.}
The cross-encoder is harmed most by truncation on long queries.
The bi-encoder mitigates this by encoding independently, but still
cannot overcome the domain mismatch between MS-MARCO short queries
and ToT narratives of 121--238 words.

\textbf{Dense first-stage retrieval remains the open problem.}
The error analysis shows that 78\% of failures arise from the R@100
ceiling. Replacing BM25 with a full dense index---encoding all 3.18M
documents with a bi-encoder and performing approximate nearest-neighbour
search---is the highest-priority direction for future work~\cite{karpukhin2020,thakur2021}.
Models that handle long-context queries, such as those fine-tuned on
narrative retrieval tasks, are also expected to improve over
MS-MARCO-trained models~\cite{bhatt2024}.

\section{Conclusion}
\label{sec:conclusion}
% ══════════════════════════════════════════════════════════════════════════════

We evaluated three retrieval systems on the TREC Tip-of-the-Tongue task:
BM25 ($k_1=1.2$, $b=0.75$), a cross-encoder reranker, and a bi-encoder
reranker, all against the same 142-query 2025/dev1 evaluation set.
BM25 achieves the best aggregate performance (RR@10~=~0.0751);
neither neural model improves significantly over it (Wilcoxon $p > 0.10$).
Subgroup analysis confirms that neural rerankers are systematically
hurt on the long narratives that define the ToT task.
Interpretability analysis reveals that the models fail because they
were trained on short keyword queries and cannot represent the full
semantic content of ToT descriptions.
The path forward is dense first-stage retrieval with models
trained---or fine-tuned---on long narrative queries.
